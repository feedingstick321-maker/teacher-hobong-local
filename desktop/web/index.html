8GB PC·자동 준비·4B 참고 후보 사용 안내

4B판에는 CPU 모델과 내부 로컬 엔진이 함께 들어 있습니다. 별도 Ollama 설치나 명령창 실행은 필요 없습니다. 앱이 전용 127.0.0.1 임시 포트에서 숨김 자식 프로세스를 자동 관리하며, 개인 서류를 외부로 보내지 않습니다. 기존 Ollama 서비스에는 접속하지 않습니다.

8GB급 PC에서는 모델을 로딩하지 않습니다. 기본 문서 읽기·규칙 추천·계산·저장은 계속 사용할 수 있습니다. 총 메모리 15GiB 이상(16GB급)이며 현재 가용 메모리 8GiB 이상일 때만 로딩합니다. 메모리 조회 실패나 부족 시 이유를 표시하며, 다른 프로그램을 닫은 뒤 AI 다시 준비해 보기로 다시 확인할 수 있습니다. 이미 준비된 모델의 추론에도 가용 메모리 2GiB 이상이 필요합니다.

64GB 검증 PC에서 모델 프로세스가 약 6~7GiB를 사용했기 때문에 보수적으로 정한 기준이며, 모든 16GB PC에서의 성능을 보장하지 않습니다. 첫 모델 로딩 시간은 사라지는 것이 아니라 앱 시작 후 백그라운드로 앞당깁니다. 준비 중에도 파일 선택과 기본정보 입력이 가능합니다.

자동 준비 체크를 끄면 다음 실행부터 규칙 모드로 시작합니다. 체크 설정만 PC의 사용자 설정 폴더에 저장하며 입력한 개인정보는 저장하지 않습니다. AI 모델 내리기는 모델과 전용 엔진을 종료해 메모리를 반환하고, 이 실행에서는 자동으로 다시 로딩하지 않습니다. AI 추천 중에는 내리기 버튼을 사용할 수 없습니다.

2단계의 4B 참고 후보 보기는 기관·직종·증빙 문장에서 참고 후보를 찾습니다. 기존 규칙 추천이나 선택한 환산율을 바꾸지 않습니다. 미확인·상충 증빙은 원본으로 확인하고 담당자가 기존 환산율 선택란에서 직접 선택해야 합니다. 준비 실패·메모리 부족 시 AI만 사용하지 않고 기본 기능을 이어갈 수 있습니다.

STEP 01 / 자료 준비

어떤 자료로 시작할까요?

증명서를 불러오거나 직접 입력할 수 있습니다. 불러온 내용은 자동 확정되지 않으니 원본과 대조해 주세요.

증명서 읽기 PDF 또는 이미지 1개

같은 대상자의 경력증명서·졸업증명서·교원자격증을 여러 쪽 PDF 1개로 준비하면 편리합니다. 필수는 아니며, 개별 PDF·이미지 1개도 읽을 수 있습니다. 파일당 50MB·30쪽 이내로 준비하세요.

분석을 다시 하면 경력이 추가됩니다. 같은 파일의 중복 추가를 자동으로 막지 않으며, 기존 학력·자격이 바뀔 수 있으니 확인하세요.

증명서 준비부터 분석 완료까지
  1. 한 사람의 서류만 준비하세요. 경력증명서와 졸업증명서, 교원자격증을 스캔할 때 여러 쪽 PDF 한 개로 저장하는 방법을 권장합니다. 없는 서류를 억지로 넣을 필요는 없으며, 인사기록카드나 개별 PDF·이미지도 사용할 수 있습니다. 다른 사람의 서류를 섞지 마세요.
  2. 글자가 잘 보여야 합니다. 스캔은 300dpi를 권장하며, 한 페이지에는 원문 1쪽씩 바른 방향으로 담으세요. 표의 끝·도장·근무기간이 잘리지 않았는지, 특히 날짜가 흐리지 않은지 확인하세요.
  3. 형식을 확인하세요. 한글·Word 문서는 먼저 PDF로 저장하고, 암호가 걸린 PDF는 열람 권한이 있는 암호 해제본을 준비하세요. 파일은 한 번에 1개, 50MB·30쪽 이내입니다. 개인정보 서류를 온라인 PDF 병합 서비스에 올리지 말고 PC에서 스캔·저장하세요.
  4. 파일 선택 → 선택한 파일 분석. 문서량과 PC 성능에 따라 수분이 걸릴 수 있습니다. 완료 전에는 다시 누르지 마세요. 완료되면 아래 성명·임용일·교원자격증·최종 학력을 확인하고 경력 검토로 계속을 누르세요.

추가 파일을 읽을 때: 기존 경력 뒤에 새 경력이 누적되며 중복을 자동 차단하지 않습니다. 같은 서류를 다시 읽었다면 2단계에서 중복 행을 삭제하세요. 학력·자격 등 기존 입력값이 바뀔 수 있으니 기본정보도 다시 대조하세요.

파일이 안 읽히거나 내용이 빠졌다면: PDF·이미지 여부, 암호, 크기·쪽 수와 선명도를 확인하고 파일을 다시 선택하세요. 원본이 흐리면 재스캔하거나 직접 입력하기로 보완할 수 있습니다.

파일은 외부로 전송되지 않습니다. 인터넷 연결 없이 이 PC의 CPU에서 처리합니다.

기존 호봉자료 가져오기 여러 파일 선택 가능

호봉획정표·재획정표·경력기간 합산신청서·시간강사 경력 환산표는 여기에서 읽으세요. 분석 → 검토표 확인 → 선택 항목 반영 순서로 진행하며, 기존 호봉을 그대로 승계하는 기능은 아닙니다.

여러 파일은 파일 선택 창에서 Ctrl 키로 고르세요. 노란 행은 원본을 확인한 뒤 직접 선택하고, 회색 행은 이미 입력된 기간인지 대조하세요.

기존 자료의 검토표·기준 정보 반영 방법
  1. 같은 대상자의 자료를 선택하세요. PDF·이미지를 여러 개 선택할 수 있습니다. Windows 파일 선택 창에서 Ctrl 키를 누른 채 파일을 클릭하세요. 각 파일은 50MB·30쪽 이내로 준비하고, 한글·Word 원문은 PDF로 저장하세요.
  2. 선택한 파일 분석을 누르고 검토표가 나올 때까지 기다리세요. 문서량과 PC 성능에 따라 수분이 걸릴 수 있습니다. 분석만으로 경력이 입력되지는 않습니다.
  3. 검토표를 원본과 대조하세요. 근무기간·기관·직종·시수·추천 유형을 확인하세요. 노란 원본 확인 행은 증빙 확인 후 체크하고, 회색 기입력 행은 같은 기간이 이미 입력되어 선택할 수 없는 항목입니다. 기간이 같아도 실제로 같은 경력인지 직접 확인하세요.
  4. 선택 항목 반영을 누르면 체크한 경력이 추가됩니다. 신규 경력만 선택은 체크 상태만 바꾸며, 닫기는 검토표만 닫습니다. 반영한 뒤에도 2단계에서 환산유형·시수·종료일 산입 여부를 확인하세요.
  5. 기준 정보 반영은 별도 버튼입니다. 판독된 소속·직위·획정일·교원자격만 기본정보에 넣으며 기존 값을 바꿀 수 있습니다. 성명·학력은 별도로 입력하고, 이번 임용일과 자격에 맞는지 확인하세요.

기존 호봉·잔여기간은 참고값입니다. 기존 계산을 무조건 승계하지 않고 반영한 경력과 입력한 기본정보로 다시 계산합니다. 잘못 읽힌 항목은 2단계에서 수정하거나 직접 추가하세요. 파일 오류는 형식·암호·크기·쪽 수·선명도를 확인한 뒤 다시 시도하세요.

STEP 01 / 입력값 확인

기본정보를 확인하세요

성명, 임용일, 교원자격증, 최종 학력은 다음 단계로 넘어가기 전에 필요합니다.

필수 입력과 조서 표기용 항목의 차이
  1. 성명·임용(시작)일: 이번 대상자의 이름과 호봉획정일을 입력하세요. 날짜는 2026-03-01처럼 연-월-일 형식입니다. 기존 표의 획정일을 가져왔더라도 이번 임용일인지 다시 확인하세요.
  2. 교원자격증·최종 학력: 이번 임용에 적용되는 자격종별과 증명서상의 학력을 선택하세요. 파일을 읽었어도 잘못 선택되거나 비어 있지 않은지 대조해야 합니다.
  3. 출력용 학력: 조서에 적을 학교·학과 이름입니다. 여기에 글자를 입력해도 계산용 최종 학력이 선택되지는 않습니다. 두 항목을 따로 확인하세요.
  4. 선택 항목: 소속·직위·작성자와 추가 표기 항목은 문서 작성에 맞게 채우고, 해당 없으면 빈칸으로 두세요. 공제 연수·필요 경력 연수는 근거 없이 추정하지 마세요. 가산연수 체크도 증빙이 있는 해당 사항만 선택하세요.

다음 단계가 열리지 않으면: 안내창에 나온 필수 항목과 날짜 형식을 고친 뒤 경력 검토로 계속을 다시 누르세요. 불러오기·직접 입력 중 어느 방법이든 같은 검토 절차를 거칩니다.

작업은 자동 임시저장되지 않습니다. 앱을 닫거나 초기화하기 전 결과를 엑셀·PDF로 저장하세요. 저장한 문서는 결과물이며 입력 상태를 그대로 복구하는 작업 파일은 아닙니다.

STEP 02 / 경력 검토

근무기간과 환산율을 확인하세요

근무기간별로 한 줄씩 입력합니다. 원본 대조 → 증빙 확인 → 환산율 선택 순서로 검토하세요. 추천 후보는 최종 확정이 아닙니다.

경력 추가·증빙 확인·환산율 추천 순서

용어 먼저 보기: 원경력기간은 입력한 근무기간에서 산입 원칙에 따라 계산한 기간이고, 환산율은 그중 호봉 산정에 인정하는 비율입니다. 이 비율을 적용한 기간이 환산경력입니다.

  1. 빠진 경력은 + 경력 직접 추가. 증명서의 근무기간별로 1행씩 작성하고, 기관명과 직종을 서로 다른 칸에 넣으세요. 예: 근무학교(회사) 가나다고등학교 / 직종 기간제교사. 중간에 끊긴 근무기간을 임의로 한 행에 합치지 마세요.
  2. 날짜와 종료일 산입을 확인하세요. 예: 시작일 2025-03-01, 종료일 2026-02-28. 원본 날짜를 그대로 넣고 마지막 날 포함 여부를 따로 확인하세요. 직접 추가한 행은 기본 해제, 문서에서 가져온 행은 기본 체크되어 있으므로 그대로 확정하지 마세요. 자세한 원칙은 아래 기간 계산 원칙과 적용 법령 보기에서 확인합니다.
  3. 증빙을 먼저 확인하세요. 각 행의 증빙에서 확인한 내용을 열고 기관의 법적 형태·근로관계·등록/신고 등 화면에 나오는 항목을 확인한 범위에서 선택한 뒤 입력한 경력으로 환산율 추천을 누르세요. 모르는 사항을 확인된 것으로 선택하지 마세요. 자격 일치·임면보고 등 추천 근거의 필수 확인사항은 별도로 원본과 대조해야 합니다.
  4. 후보와 실제 선택값을 구분하세요. 후보·근거·필수 확인사항을 읽고 증빙과 일치할 때 후보 버튼이나 경력 환산율 선택에서 적용 유형을 고르세요. 후보 버튼을 누르면 직접 선택값으로 적용됩니다. 위쪽 추천 유지는 미확인 경력을 자동 확정하는 기능이 아닙니다. 환산율 초기화는 추천으로 적용된 환산유형을 비우므로 다시 선택해야 합니다.
  5. 확인 필요 표시를 해결하세요. 주황색 안내와 필요한 증빙을 읽으세요. 교습소 경력의 확인 필요 버튼은 추가 안내창을 엽니다. 입력을 바꿨다는 안내가 나오면 증빙과 추천을 다시 검토하고, 시수·근무시간 입력란이 나타나면 원본을 보고 채우세요.
  6. 빈 행·중복 행은 삭제하고 결과 확인하기. 각 행의 삭제는 해당 경력만 지웁니다. 결과로 넘어가지 못하면 안내창의 행 번호를 찾아 환산율·시작일·종료일·기간 순서를 수정하세요. 현재 앱은 경력 1건 이상이 있어야 결과를 계산합니다.

입력 화면 합계만으로 끝내지 마세요. 3단계에서 중복기간 조정과 최종 산정 결과를 다시 확인합니다. 기본정보가 틀렸다면 자료 입력으로 돌아가기로 수정할 수 있습니다.

STEP 03 / 결과 확인

산정 결과를 원본과 대조하세요

산정 호봉·잔여기간·중복 조정·잠정 환산율을 검토한 뒤 엑셀과 PDF를 각각 저장하세요.

결과 검토·엑셀/PDF 저장·다시 시작하는 방법

계산 흐름 이해하기: 기산호봉은 선택한 교원자격을 바탕으로 계산을 시작하는 호봉입니다. 화면은 여기에 학력에 따른 가감·해당 가산연수·환산경력을 반영해 산정 과정을 보여 줍니다. 잔여기간은 호봉에 반영한 연수 뒤에 남는 월·일로, 다음 승급 시기 검토에 쓰입니다.

  1. 계산 근거를 확인하세요. 대상자·임용일·자격·학력과 산정 호봉, 잔여기간, 호봉 산정 과정, 경력 환산 상세내역을 원본과 대조하세요. 중복기간의 조정 내역과 후보·확인 필요 등 잠정 환산율이 남아 있는지 확인해야 합니다.
  2. 틀린 값은 앱에서 수정하세요. 경력 수정하기로 2단계에 돌아가 수정하고 결과 확인하기를 다시 누르세요. 기본정보는 위쪽 자료 입력 단계에서 고칩니다.
  3. 엑셀 저장은 .xlsx, PDF 저장은 .pdf 문서를 만듭니다. 필요한 형식을 각각 눌러 저장 창에서 위치·파일명을 선택하고 저장 완료 안내를 확인하세요. 저장 창을 취소하면 파일이 저장되지 않습니다.
  4. 실제 파일도 열어 확인하세요. 선택한 폴더에서 이름·날짜·경력·호봉·출력 누락 여부를 확인하세요. 저장 오류가 나면 쓰기 가능한 다른 폴더를 선택하고, 같은 이름의 파일이 열려 있으면 닫은 후 다시 저장하세요.
  5. 닫기·초기화 전에 저장하세요. 자동 임시저장은 없습니다. 처음부터 다시는 확인 후 입력값·파일 선택·분석 검토표를 모두 비워 다른 대상자를 시작하게 합니다. 이미 저장한 파일과 원본은 지우지 않습니다.

저장 문서와 앱은 연결되어 있지 않습니다. 엑셀·PDF의 내용을 수정해도 앱에 자동 반영되지 않습니다. 저장 파일은 결과 문서이지 입력 상태를 그대로 이어가는 작업 파일이 아니므로, 앱에서 수정한 뒤 새 결과를 다시 저장하세요.
